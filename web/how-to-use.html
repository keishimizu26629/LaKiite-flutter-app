LaKiiteの使い方

フレンドやリストに予定を共有し、相手の反応を確認するまでの基本操作をまとめています。

フレンド追加

予定を共有するには、まず相手とフレンドになる必要があります。検索IDを使って相手を探し、申請を送ります。

追加の流れ

  1. 「フレンド」タブを開きます。
  2. 相手の検索IDを入力してユーザーを検索します。
  3. 表示された相手を確認し、フレンド申請を送ります。
  4. 相手が承認すると、予定の共有先として選べるようになります。

検索IDについて

検索IDは、相手を探すためのIDです。名前が同じユーザーがいても、検索IDを使うことで目的の相手を見つけやすくなります。

相手が見つからない場合は、検索IDの入力間違いや、相手が設定しているIDをもう一度確認してください。

リストの使い方

リストは、複数のフレンドへまとめて予定を共有したいときに使います。家族、仕事、友人グループなどの単位で作ると便利です。

リストでできること

  • よく共有する相手をひとつのグループにまとめられます。
  • 予定作成時にリストを選ぶだけで、複数人へ一度に共有できます。
  • リストのメンバーを変更すると、次に共有する予定から新しいメンバー構成を使えます。

使いどころ

毎回同じ相手に予定を共有する場合は、個別にフレンドを選ぶよりもリストを使う方が手間を減らせます。

「家族」「チーム」「週末メンバー」のように、あとから見ても分かりやすい名前にしておくと管理しやすくなります。

予定作成

予定にはタイトル、日時、メモ、共有先を設定できます。共有先を選ばない場合は、自分だけの予定として保存されます。

作成の流れ

  1. 予定作成画面を開きます。
  2. 予定のタイトルを入力します。
  3. 開始日時と終了日時を設定します。
  4. 必要に応じてメモを入力します。
  5. 共有したいフレンドまたはリストを選びます。
  6. 内容を確認して保存します。

共有先の考え方

個別の相手にだけ伝えたい予定はフレンドを選び、複数人へまとめて伝えたい予定はリストを選びます。

まだ共有先を決めていない予定は、共有先を選ばずに保存しておき、あとから編集で追加できます。

予定の確認

作成した予定や共有された予定は、ホームやカレンダーから確認できます。共有予定では、相手のリアクションやコメントも確認できます。

予定を見る

  • 今日の予定はホームで確認できます。
  • 日付をまたいで確認したい場合は、カレンダーから目的の日を開きます。
  • 予定を開くと、日時やメモなどの詳細を確認できます。

リアクション・コメント

共有された予定には、相手がリアクションやコメントを追加できます。参加できるか、確認したか、補足したいことがあるかをやり取りするために使います。

予定の内容を変更した場合は、共有相手にも更新後の内容が表示されます。重要な変更をしたときは、コメントでも補足しておくと伝わりやすくなります。

通知設定

通知を使うと、共有されている予定に気づきやすくなります。朝の共有予定通知では、その日に共有されている予定を指定した時刻に受け取れます。

設定できること

  • 朝の共有予定通知をオン・オフできます。
  • 通知を受け取る時刻を変更できます。
  • 共有予定がある日だけ通知を受け取れます。

変更方法

  1. 設定画面を開きます。
  2. 「朝の共有予定通知」を選びます。
  3. 通知のオン・オフや時刻を変更します。
  4. 保存して設定を反映します。

端末側で通知が許可されていない場合、アプリ内で通知をオンにしていても通知が届かないことがあります。
