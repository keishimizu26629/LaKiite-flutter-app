LaKiiteの使い方

フレンドやリストに予定を共有し、相手の反応を確認するまでの基本操作をまとめています。

フレンド追加

予定を共有するには、まず相手とフレンドになる必要があります。検索IDを使って相手を探し、申請を送ります。

追加の流れ

  1. 「フレンド」タブを開きます。
  2. 相手の検索IDを入力してユーザーを検索します。
  3. 表示された相手を確認し、フレンド申請を送ります。
  4. 相手が承認すると、予定の共有先として選べるようになります。

友人をアプリに招待する

フレンド検索画面の「友人をアプリに招待する」から、アプリをまだ使っていない人にも、すでに使っている人にも、フレンド追加の招待を送れます。

LaKiiteを使ってほしい友人に送ってください。

検索IDについて

検索IDは、相手を探すためのIDです。名前が同じユーザーがいても、検索IDを使うことで目的の相手を見つけやすくなります。

自分の検索IDは、マイページの表示名の下に表示されています。検索IDをタップするとコピーできるので、フレンドになりたい相手へそのまま共有できます。

検索IDを変更したい場合は、設定画面の「検索ID」から変更できます。

相手が見つからない場合は、検索IDの入力間違いや、相手が設定しているIDをもう一度確認してください。

リストの使い方

リストには「公開用」と「表示用」があります。どちらも自分の中だけで使うリストなので、リスト名やメンバーが他の人に知られることはありません。

公開用リスト

公開用リストは、自分の予定を誰に公開したいかを決めるためのリストです。家族、仕事、友人グループなど、予定を見せたい相手をまとめておくと、予定作成時にリストを選ぶだけで複数人へ一度に共有できます。

  • 同じフレンドを複数の公開用リストに入れられます。
  • 予定ごとに、公開したい範囲に合わせてリストを選べます。

表示用リスト

表示用リストは、友達から公開された予定を「自分にとってどの部類の人が公開してきた予定か」で見分けやすくするためのリストです。表示用リストに色を設定すると、カレンダー上の予定の色がそのリストに合わせて変わります。

  • 同じフレンドは、複数の表示用リストには入りません。
  • 「ラグビー部」「子連れ」「地元」など、自分が予定を見分けやすい単位で作れます。
  • 公開範囲を決めるためのリストではなく、予定を見やすく整理するためのリストです。

公開用は「誰に見せるか」、表示用は「誰からの予定として色分けして見るか」を決めるものです。

予定作成

予定にはタイトル、日時、メモ、共有先を設定できます。共有先を選ばない場合は、自分だけの予定として保存されます。

作成の流れ

  1. 予定作成画面を開きます。
  2. 予定のタイトルを入力します。
  3. 開始日時と終了日時を設定します。
  4. 必要に応じてメモを入力します。
  5. 共有したいフレンドまたはリストを選びます。
  6. 内容を確認して保存します。

共有先の考え方

個別の相手にだけ伝えたい予定はフレンドを選び、複数人へまとめて伝えたい予定はリストを選びます。

まだ共有先を決めていない予定は、共有先を選ばずに保存しておき、あとから編集で追加できます。

予定の確認

作成した予定や共有された予定は、カレンダーやタイムラインから確認できます。予定にはリアクションやコメントもできます。

予定を見る

  • ホームには月次カレンダーが表示されます。
  • 月次カレンダーの日付をタップすると、その日の予定を日次カレンダーで確認できます。
  • タイムラインでは、本日以降の直近の予定が上から順に表示されます。
  • 自分の予定は、必要に応じて非表示にできます。
  • 予定を開くと、日時やメモなどの詳細を確認できます。

予定の色分け

友達から公開された予定は、表示用リストに設定した色に合わせてカレンダー上の色が変わります。誰から公開された予定なのかを、自分にとって分かりやすい分類で確認できます。

リアクション・コメント

予定にはリアクションやコメントを追加できます。参加できるか、確認したか、補足したいことがあるかをやり取りするために使います。

予定の内容を変更した場合は、共有相手にも更新後の内容が表示されます。重要な変更をしたときは、コメントでも補足しておくと伝わりやすくなります。

端末引き継ぎ

暗号化された予定を別の端末でも開くには、元の端末で端末引き継ぎ設定を保存し、復元パスワードを控えておく必要があります。

引き継ぎ前に行うこと

  1. 元の端末で設定画面を開きます。
  2. 「端末引き継ぎ設定」を選びます。
  3. 復元パスワードを入力し、確認用にも同じパスワードを入力します。
  4. 保存すると、予定を開くための秘密キーが復元パスワードで暗号化されて保存されます。

別端末で復元する

  1. 新しい端末で同じアカウントにログインします。
  2. 端末引き継ぎ画面が表示されたら、元の端末で設定した復元パスワードを入力します。
  3. 復元が完了すると、暗号化された予定を新しい端末でも表示できます。

復元パスワードを変更する

端末引き継ぎ設定が保存済みの場合でも、新しい復元パスワードで保存できます。保存すると既存の引き継ぎ設定は上書きされ、次回から別端末で復元するときは新しい復元パスワードが必要になります。

復元パスワードはアプリ内で確認できません。端末引き継ぎ設定をしていない場合や復元パスワードを忘れた場合、別端末では暗号化された予定を開けません。

通知設定

通知を使うと、共有されている予定に気づきやすくなります。朝の共有予定通知では、その日に共有されている予定を指定した時刻に受け取れます。

設定できること

  • 朝の共有予定通知をオン・オフできます。
  • 通知を受け取る時刻を変更できます。
  • 共有予定がある日だけ通知を受け取れます。

変更方法

  1. 設定画面を開きます。
  2. 「朝の共有予定通知」を選びます。
  3. 通知のオン・オフや時刻を変更します。
  4. 保存して設定を反映します。

端末側で通知が許可されていない場合、アプリ内で通知をオンにしていても通知が届かないことがあります。
