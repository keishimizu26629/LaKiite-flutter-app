# 日本語ストア文言・7枚の画像構成案

更新日: 2026-09-08 / Refs #315, #310

対象読者: ストア素材の制作担当と、掲載判断を行うプロダクトオーナー。

推奨は **LaKiite（ラキーテ）予定共有カレンダー**。英字名・読み仮名・用途を名前に揃え、「お誘い未満」は用途を理解した後に伝える。狙いは、口コミで聞いた名前との一致と、初見での用途理解を助けること。検索順位・ダウンロード増加は未検証であり、保証しない。

これは編集・比較用のドラフト。App Store Connect / Play Consoleへの入力、審査提出、公開は行っていない。

- [screenshots.json](screenshots.json): 7枚の順番、見出し、メッセージ、撮影指示、既存画像の制約。

- [実装計画](../../issue-315-implementation-plan.md) / [検証記録](../../issue-315-verification.md)。

既存LPにもdescription・本文にはラキーテの表記があった。今回のLP修正は、title/OG/Twitter/構造化データの別名と、最初に見えるブランド・h1まで用途と読み仮名を揃えるもの。ロゴ、アプリ挙動、計測の実装は変更しない。

## 文言2案と採用理由

| 項目 | A: purpose_first（推奨） | B: positioning_first（比較用） |
|---|---|---|
| 両ストアの名前 | LaKiite（ラキーテ）予定共有カレンダー | ラキーテ（LaKiite）お誘い未満の予定共有 |
| 名前の文字数 | 22 | 23 |
| Appleサブタイトル | 誘うほどでもない日も、気軽につながる | 友だちとつながるカレンダー |
| サブタイトル文字数 | 18 | 13 |
| Appleキーワード | スケジュール,友達,おでかけ,休日,遊び,約束 | スケジュール,おでかけ,休日,遊び,約束 |
| キーワード文字数 / UTF-8 bytes | 23 / 59 | 20 / 52 |
| Appleプロモーション文字数 | 75 | 67 |
| Apple説明文字数 | 340 | 230 |
| Play短い説明 | 友だちと予定を共有できるカレンダー。お誘い未満の予定も気軽にシェア。 | お誘い未満の予定を友だちにシェア。会うきっかけをつくるカレンダー。 |
| 短い説明文字数 | 34 | 33 |
| Play詳細説明文字数 | 352 | 218 |

文字数はUnicodeコードポイント単位、改行も1文字で計測。最終的には対象ロケールのConsoleで制限と表示を再確認する。Aは名前だけでカレンダーと理解できる。Bは口コミでコンセプトを知っている人に向く仮説だが、用途の即時理解を優先してAを採る。2案を同時掲載するものではなく、A/Bテストも実施していない。

全文はJSONを正として、例えば次で個別項目を取り出す（ローカル出力のみ）。

```bash
jq -r '.variants[] | select(.id == "purpose_first") | .apple.description' docs/marketing/store/ja-JP/copy.json
jq -r '.variants[] | select(.id == "purpose_first") | .googlePlay.shortDescription' docs/marketing/store/ja-JP/copy.json
```

更新説明は `verify_against_target_release_before_upload`。対象バージョンの実差分と照合し、含まれていない改善は削除する。Play向けにiOSの修正やAirbridge等の実装用語を転記しない。

## 検索意図と配置

| 意図の仮説 | 候補語 | 配置と理由 |
|---|---|---|
| 口コミで聞いたアプリを探す | ラキーテ / LaKiite | 名前、LP title、可視ブランド、説明冒頭。表記の一致を助ける |
| 予定共有の道具を探す | 予定共有 / カレンダー | 名前と最初の画像。製品カテゴリを早く伝える |
| 友人とスケジュールを合わせたい | 友だち / 友達 / スケジュール | 可視説明で対象者を限定。Appleでは名前等にない補助語をキーワード欄に配置 |
| 会うきっかけを探す | おでかけ / 休日 / 遊び / 約束 | 説明の利用例とAppleの補助語。広い意図なので優先度は低い |
| ブランドの独自性を理解する | お誘い未満 | サブ訴求と説明。検索需要が実証された語とは扱わない |

候補は公開文言と製品適合性から選定。検索ボリューム、難易度、非公開キーワード、検索順位のデータは取得していない。語の詰め込みや同義語の大量列挙、競合名をキーワードへ入れることはしない。Appleは名前・サブタイトル・キーワードの役割を分け、Playは自然な説明文で用途を補足する。

競合文言との対応: 読み仮名の併記はTimeTree、カレンダー・予定共有と家族/友人の用途説明は下記2件を参照。「おでかけ・休日・遊び・約束」は競合の上位語を確認できたわけではなく、LaKiiteの利用例から置いた低優先度候補。「お誘い未満」はLaKiite側の独自訴求であり、競合由来の需要語ではない。

## 先頭3枚と7枚の撮影順

| 順番 | 伝えること | 必要な画面・制約 |
|---|---|---|
| 1 | 友だち向け予定共有カレンダー | 予定2〜3件が見えるカレンダー。用途を最初に理解させる |
| 2 | 予定を作り、シェアできる | 共有後の詳細。参考画像で開いているリアクションメニューを閉じて撮り直す |
| 3 | 友だちの予定から会うきっかけ | テスト用フレンドの予定が見えるタイムライン。旧画像は自分の予定なので流用不可 |
| 4 | 共有先を選べる | 現行の公開範囲・リスト選択。参考画像なし、要撮影 |
| 5 | 気になる予定に反応 | リアクションとコメント導線。架空のテストデータのみ |
| 6 | 友だちを招待できる | 対象版の招待画面。実ユーザーにつながるコード・リンク・IDを入れない |
| 7 | お誘い未満という利用場面 | 散歩・お出かけ等の小さな予定を示して締める |

全7枚で `requiresRecapture: true`。既存画像は過去のiOS参考画像のみで、Android画像は未撮影。iPhone画面をAndroid画面に見せかけない。UIを捏造して機能の証拠にしない。プレビューは読みやすさの確認用で、文字拡大時は高さが伸びる。ストア指定サイズの画像書き出し機能ではない。

### ローカルで構成案を開く

コミット済みのこのブランチで、公開画像と構成案だけを一時フォルダへ書き出す。リポジトリ全体をHTTP配信せず、`.ai`、環境設定、Git管理情報を配信対象に含めない。

```bash
preview_dir=$(mktemp -d)
git archive HEAD docs/marketing/store/ja-JP web/images | tar -x -C "$preview_dir"
python3 -m http.server 8766 --bind 127.0.0.1 --directory "$preview_dir"
```

ブラウザで `http://127.0.0.1:8766/docs/marketing/store/ja-JP/preview.html` を開く。停止はCtrl-C。画像構成の文言・素材を変更したらcommitし、新しい一時フォルダへ再出力する。JSON読み込みにHTTPが必要なため、HTMLの直接ダブルクリックでは開かない。

## 公式仕様と公開前の確認

確認日: 2026-09-08。ローカルSkillにある一般的な数値より、以下の現行公式説明とConsoleの検証を優先する。

- [Apple: Product page](https://developer.apple.com/app-store/product-page/): 名前30文字、サブタイトル30文字、プロモーション170文字、キーワード100文字。キーワードはカンマ区切りで名前等との重複を避ける。本案は念のため100 UTF-8 bytesにも収める。最大10枚、動画がなければ向きによって先頭1〜3枚が検索結果に出るため、用途を先頭で伝える。実際のUI画像を使う。
- [Apple: Version information](https://developer.apple.com/help/app-store-connect/reference/app-information/platform-version-information): こちらの入力欄リファレンスではキーワード上限を100 bytesと案内。上記製品ページの100文字表記と区別し、本案は両方を満たす。説明等の入力欄を掲載対象のプラットフォームで確認する。Apple説明は4,000文字以内を機械検査。
- [Google: メインのストア掲載情報](https://support.google.com/googleplay/android-developer/answer/9859152?hl=ja): 名前30文字。日本語ヘルプは短い説明を半角80/全角40文字、詳細を半角4,000/全角2,000文字と案内。本案とテストは保守的に短い説明40、詳細2,000文字以下とする。
- [Google: プレビューアセット](https://support.google.com/googleplay/android-developer/answer/9866151?hl=ja): 対応デバイスタイプごとに最大8枚。実際の体験を示す。フィーチャーグラフィックは1024×500。本PRにはフィーチャーグラフィックの最終画像を含まない。既存素材の有無と整合も掲載時に確認する。
- [Google Search: Title links](https://developers.google.com/search/docs/appearance/title-link): 分かりやすく簡潔なtitleと主要見出しを揃える。検索結果のタイトルはGoogleが生成するので、指定文字列で必ず表示されるとは説明しない。

入稿時はAppleの対象端末サイズ、Playの対象デバイス・画像サイズ・ファイル制限をConsoleと公式仕様で再確認する。構成案のCSSサイズを入稿寸法として使わない。字幕OCRの検索効果、表示回数改善率、競合の検索順位は裏付けがないため根拠にしない。
